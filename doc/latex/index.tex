Option Pricer -\/ комплексная библиотека для оценки финансовых опционов и анализа рисков. Библиотека предоставляет реализацию классических моделей ценообразования, методов численного анализа и инструментов для работы с рыночными данными.\hypertarget{index_architecture_sec}{}\doxysection{\texorpdfstring{Архитектура библиотеки}{Архитектура библиотеки}}\label{index_architecture_sec}
