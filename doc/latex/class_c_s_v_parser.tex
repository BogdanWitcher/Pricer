\doxysubsection{Detailed Description}
Класс для парсинга CSV файлов с рыночными данными 

Обеспечивает чтение и обработку данных из CSV файлов, преобразование в структуры \doxylink{struct_market_data}{Market\+Data} и поиск по тикерам.
