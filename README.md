**Профессиональная C++ библиотека для оценки финансовых опционов и анализа рисков**

## О проекте

Option Pricer - это высокопроизводительная C++ библиотека для оценки финансовых деривативов, реализующая классические модели ценообразования опционов.

### Основные возможности

- **Модели ценообразования** - Блэка-Шоулза, расчет подразумеваемой волатильности
- **Типы опционов** - ванильные (Call/Put), барьерные опционы
- **Анализ рисков** - полный расчет греков (Delta, Gamma, Vega)
- **Обработка данных** - загрузка рыночных данных из CSV
- **Численные методы** - интегрирование, статистические функции

### Структура модулей
🧮 Математический модуль (math/)
 - Гауссова квадратура - точное численное интегрирование
 - Статистические функции - нормальное распределение (PDF/CDF)
 - Универсальный интегратор - адаптивные методы

📊 Модуль рыночных данных (market/)
 - CSV парсер - чтение и обработка финансовых данных
 - Валидация данных - проверка корректности входных параметров
 - Абстрактный загрузчик - единый интерфейс для различных источников

💹 Модуль моделей (models/)
 - Абстрактная модель - единый интерфейс для всех моделей ценообразования
 - Блэк-Шоулз - классическая модель с калибровкой
 - Иерархия опционов - расширяемая система типов деривативов

### Сборка проекта
```
# Клонирование репозитория
git clone <your-repo-url>
cd option-pricer

# Создание директории для сборки
mkdir build && cd build

# Конфигурация проекта
cmake ..

# Сборка
make -j$(nproc)

# Запуск
./option_pricer
```
