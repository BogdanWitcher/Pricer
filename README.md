##Option Pricer## - это комплексная C++ библиотека для оценки финансовых деривативов, предоставляющая:

 - 📈 Модели ценообразования - классические и современные методы оценки опционов
 - 🧮 Численные методы - точные вычисления и интегрирование
 - 📊 Обработка данных - загрузка и анализ рыночных данных
 - 📉 Анализ рисков - расчет греков и чувствительности

** Структура модулей**
🧮 Математический модуль (math/)
 - Гауссова квадратура - точное численное интегрирование
 - Статистические функции - нормальное распределение (PDF/CDF)
 - Универсальный интегратор - адаптивные методы

📊 Модуль рыночных данных (market/)
 - CSV парсер - чтение и обработка финансовых данных
 - Валидация данных - проверка корректности входных параметров
 - Абстрактный загрузчик - единый интерфейс для различных источников

💹 Модуль моделей (models/)
 - Абстрактная модель - единый интерфейс для всех моделей ценообразования
 - Блэк-Шоулз - классическая модель с калибровкой
 - Иерархия опционов - расширяемая система типов деривативов

🔬 **Математическая основа**
Библиотека реализует классическую формулу Блэка-Шоулза:

**Сборка проекта**
```
# Клонирование репозитория
git clone <your-repo-url>
cd option-pricer

# Создание директории для сборки
mkdir build && cd build

# Конфигурация проекта
cmake ..

# Сборка
make -j$(nproc)

# Запуск
./option_pricer
```
